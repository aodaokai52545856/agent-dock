# UI 检查与体验优化（2026-10-25）

## 布局与信息层级

- 侧栏会话标题、工具筛选、运行筛选和批量操作原先挤在一行，280px 默认宽度已发生截断；改为标题操作、筛选两行布局。
- “全部”视图收起没有会话的工具分组，减少重复空态。搜索无结果时提供“清除搜索”，没有会话时提供创建入口。
- 窄窗口状态栏保留终端、用量和常用操作，按宽度减少路径等辅助信息，避免文字换行后被 28px 高度裁切。
- 标题栏兼容 18px 界面字号和窄窗口；时钟、消耗浮层以及通用弹窗限制在可见高度内。
- 空工作区采用三列工具入口，按实际终端区域宽度变为两列或单列，内容过高时可滚动。
- 版本卡片按可用宽度排列，操作按钮允许换行；账号名称、邮箱和项目路径处理长文本。
- 浅色滚动条使用对应的深色描边，侧栏标题提高可读性。

## 操作与反馈

- 设置分为外观、终端与工具、自动化，标题和保存区域固定，内容独立滚动。
- 明确区分外观自动保存与工具配置手动保存；存在未保存配置时关闭会提示，继续编辑会保留草稿。
- 新建会话预选最近使用的工具，保留项目选择；项目选择菜单先响应 Esc，第二次 Esc 才关闭弹窗。
- 项目支持粘贴路径、Enter 提交、字段失焦校验和首个错误聚焦；错误显示在对应字段，提示行高度稳定，避免点击保存时布局移动。
- 会话提供可发现的操作菜单入口，保留原有右键操作。刷新会话时保留列表和滚动位置，用非阻塞状态提示进度。
- 通用弹窗统一管理 Tab、Shift+Tab、Esc、焦点恢复和嵌套弹窗；危险确认默认聚焦取消。
- 编排画布快捷键只在编排模式中处理，弹窗中的 Delete / Esc 不再影响背景节点。
- 文本转换入口仅在控制台显示，避免覆盖编排角色库；提示消息支持长文本并显示在浮层上方。

## 验证

- `npm run build`：类型检查与生产构建通过。
- 14 组前端测试通过：pack、fit、layout、clock、bridge、flow、usage、appearance、cite、convert、ccswitch、claude、dsh、live。
- 修复两处既有测试对运行环境的依赖：重置时间使用本地日期样本，图表测试使用固定 12 小时数据，避免时区或午夜运行造成误报。
- 会话打开逻辑的回归通过语法树定位 `openSession`，避免新增相邻函数后把其他逻辑误算进测试范围。
- `scripts/ui-layout-smoke.js`：深浅主题、1440 / 1024 / 800 / 680px 宽度、360 / 400px 短窗口、18px 字号、240px 侧栏，共 13 组尺寸与字号组合；覆盖设置保存、未保存草稿、项目表单、搜索、账号弹窗、画布快捷键隔离和嵌套焦点恢复。
- `scripts/claude-accounts-ui-smoke.js`：创建、登录失败后检查、默认账号、取消登录、迁移、移除和身份冲突等原有流程通过。

浏览器回归使用 Vite 预览和模拟数据，不会读取或变更本机账号、凭据或真实项目设置。系统文件夹选择器、原生窗口操作和桌面毛玻璃效果需要在桌面包中人工确认。
