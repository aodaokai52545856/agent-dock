# 简繁与符号清洗浮动工具

Date: 2026-10-18  
Status: approved  
Approach: 前端浮动面板 + 纯 TypeScript 转换（方案 A）

## Goal

在 Agent Dock 控制台和编排模式都提供一个右下角常驻浮动按钮。点开后贴入中文，可将简体转为繁体字形，并把中文/全角标点、全角字母数字换成英文半角符号。结果出现在面板里，可再改，再复制。

硬约束：**每个码点必须归类。没有映射或不允许保留的字符一律删除，禁止原样漏出。**

## Background

Agent Dock 是 Tauri 2 + Vue 3 驾驶舱。弹窗都是居中 `ad-dialog`，右下角已有会话完成 toast（`bottom: 44px; right: 16px`），没有现成 FAB。转换是本地文本工具，不经过 PTY、不写会话、不走网络。

用户选择：

- 结果在面板显示，可编辑后再复制
- 「转繁体」「洗符号」可分开点，另加「全部转换」
- 繁体只换字形（「软件」→「軟件」），不用词组表
- 全角标点/字母/数字/括号转半角；汉字保留；没有 ASCII 对应的 emoji 和符号删除
- 按钮右下角常驻，两种模式都能用

## Non-goals

- 拖动按钮或记住位置
- 刷新/退出后保留原文
- 把结果贴进当前终端
- 词组级简繁（「软件」→「軟體」）
- 台湾/香港用词、香港字形集
- 保留 emoji 或拉丁扩展字母
- Rust / Tauri 命令做转换
- 居中模态遮罩

## Success

1. 控制台和编排都能看到右下角浮动按钮，点开是浮层面板（不挡整屏）。
2. 原文框粘贴中文后，「转繁体 / 洗符号 / 全部转换」把结果写入结果框，结果可改。
3. 「复制」把结果框当前内容写入系统剪贴板。
4. 输出中每个字符要么是汉字，要么是允许的 ASCII。任何未映射特殊字符都不得出现在输出里。
5. `npm run test:convert` 覆盖映射、删除、以及全角块/CJK 标点块扫表不漏原符。

## Architecture

挂在 `App.vue` 最外层，两种 `appMode` 共用一份实例。不走 Rust。

| 部分 | 位置 | 职责 |
|------|------|------|
| 浮动按钮 + 面板 | `src/components/TextConvertFab.vue` | 右下角按钮；展开浮层面板 |
| 转换纯函数 | `src/lib/textConvert.ts` | s2t 字形、全角/标点映射、封闭分类删除 |
| 测试 | `src/lib/textConvert.test.ts` | 映射、删除、禁止漏字符 |
| 简繁表 | OpenCC `s2t` 字符级（不用 STPhrases / s2twp） | 「软件」→「軟件」 |

按钮 `position: fixed; right: 16px; bottom: 56px; z-index: 35`（工作区内容之上，完成 toast 的 40 之下）。`bottom: 56px` 避开状态栏。面板从按钮向上展开，背景 `--ad-float`。

完成 toast 出现时允许短暂靠近，不为此做避让动画。

## UX

圆形按钮，`aria-label`「文本转换」。再点一次或 Esc 收起。不铺全屏遮罩，终端和编排画布仍可操作。

面板约 420×480：

1. **原文** 多行，上半，可粘贴。
2. **结果** 多行，下半，转换写入，可再改。
3. **按钮行：**「转繁体」「洗符号」「全部转换」；右侧「复制」。

| 操作 | 读 | 写结果框 |
|------|----|----------|
| 转繁体 | 原文 | s2t 字形 + 封闭分类（标点/全角映射，不能映射的删） |
| 洗符号 | 原文 | 不做简繁，只封闭分类。汉字保持简体 |
| 全部转换 | 原文 | 与「转繁体」相同（第一版 `traditional` 和 `all` 输出相同） |
| 复制 | 结果框 | 系统剪贴板；成功 toast「已复制」。结果为空则按钮不可用 |

每次转换从**原文**重算，不拿结果做二次加工。结果改过后再点转换会覆盖修改。

原文和结果不写 localStorage。关掉面板文字还在内存里；刷新或退出应用后清空。

空原文时三个转换按钮不可用。转换后结果与原文相同仍写入结果框，不算错误。

## Data flow

```ts
type ConvertMode = 'traditional' | 'symbols' | 'all'

function convertText(input: string, mode: ConvertMode): string
function isAllowedOutputChar(ch: string): boolean
```

`traditional` 与 `all` 第一版走同一条流水线，两个 mode 都保留，方便以后拆开「只转繁体、不动标点」。`symbols` 跳过 s2t。

面板调用 `convertText` 后写入结果 ref。复制走现有前端剪贴板路径（与其它 toast 一样，失败不关面板）。

## Character pipeline

按 Unicode **码点**遍历（`for...of` 字符串迭代器，处理 surrogate）。每个码点只进下列分支，没有「原样留下」：

```
若 mode 为 traditional | all：先做 s2t 字形（字符级）
  → 允许的 ASCII？保留
  → 汉字？保留
  → 映射表有对应？替换为允许的 ASCII（可多字符，如 … → ...）
  → 删除
```

映射结果必须全部是允许的 ASCII。缺映射 = 删除。

### 允许的 ASCII（保留）

- U+0009 Tab
- U+000A LF
- U+000D CR
- U+0020–U+007E 空格到 `~`

其它控制符删除。

### 汉字（保留）

统一汉字及扩展 A–I、兼容汉字：

- U+3400–U+4DBF
- U+4E00–U+9FFF
- U+F900–U+FAFF
- U+20000–U+2A6DF
- U+2A700–U+2B73F
- U+2B740–U+2B81F
- U+2B820–U+2CEAF
- U+2CEB0–U+2EBEF
- U+2EBF0–U+2EE5F
- U+2F800–U+2FA1F
- U+30000–U+3134F
- U+31350–U+323AF

康熙部首、笔画、注音、假名、韩文 **不是汉字**。无 ASCII 映射则删除。s2t 表没有的汉字保持原字（仍是汉字）。

### 映射表

| 来源 | 结果 |
|------|------|
| 全角 U+FF01–U+FF5E | 码点减 `0xFEE0` 得到对应半角 |
| 全角空格 U+3000 | 空格 |
| `，` U+FF0C、`、` U+3001 | `,` |
| `。` U+3002、`．` U+FF0E | `.` |
| `：` U+FF1A | `:` |
| `；` U+FF1B | `;` |
| `？` U+FF1F | `?` |
| `！` U+FF01 | `!` |
| `（）` U+FF08 U+FF09 | `()` |
| `【】` U+3010 U+3011、`〔〕` U+3014 U+3015、`「」` U+300C U+300D、`『』` U+300E U+300F、`〖〗` U+3016 U+3017、`〘〙` U+3018 U+3019、`〚〛` U+301A U+301B | `[]` |
| `《》` U+300A U+300B | `<<` `>>` |
| `〈〉` U+3008 U+3009 | `<>` |
| `“”` U+201C U+201D、`〝〞` U+301D U+301E | `"` |
| `‘’` U+2018 U+2019 | `'` |
| `…` U+2026、`⋯` U+22EF | `...` |
| `—` U+2014、`–` U+2013、`―` U+2015、`－` U+FF0D | `-` |
| `·` U+00B7、`・` U+30FB、`･` U+FF65 | `.` |
| 不间断空格 U+00A0 | 空格 |
| `«»` U+00AB U+00BB | `"` |

U+FF01–U+FF5E 的公式已覆盖全角逗号、句号、括号、字母、数字；上表重复列出的是便于对照。同一码点只映射一次。

全角块其余已分配字符（半角片假名 U+FF61–U+FF9F、半角韩文、货币 U+FFE0–U+FFE6 含 `￥`）**没有 ASCII 对应 → 删除**，不输出原符。

### 删除

包括但不限于：emoji 及 ZWJ 序列、变体选择符、零宽字符、BOM、装饰符、私用区、拉丁扩展（如 `é`）、数学/货币/特殊符号、以及未命中「允许 ASCII / 汉字 / 映射表」的任何码点。

## Error handling

- 空字符串 → 返回空字符串，不抛错。
- 剪贴板失败 → toast「复制失败」，面板不关、文字不丢。
- OpenCC 表加载失败 → 三个转换按钮不可用，面板提示「转换表不可用」。正常 dev/build 必须带上表；测试读取同一份表。
- 不请求网络、不写磁盘、不改会话。

## Testing

`src/lib/textConvert.test.ts`，npm 脚本 `test:convert`。

| 用例 | 断言 |
|------|------|
| `软件（测试），。` + `all` | `軟件(測試),.` |
| 全角 `ＡＢＣ（１２３）` + `symbols` | `ABC(123)` |
| `symbols` | `软件` 仍简体，`，` 变 `,` |
| 混入 emoji、`￥`、零宽、`é` | 这些码点从输出消失 |
| 不变量 | 每条用例每个输出字符 `isAllowedOutputChar` |
| 遍历 U+FF00–U+FFEF、U+3000–U+303F 已分配码点 | 输出中不得再出现这些块的原字符 |
| 空输入 | `''` |
| `traditional` 与 `all` 对同一输入输出相同 | 第一版契约 |

面板不做组件快照。不单测 Tauri 剪贴板。

## Implementation notes

- `isAllowedOutputChar` 与转换器共用同一套汉字范围和 ASCII 白名单，禁止两套规则漂移。
- 扫表测试把「映射或删除」做成封闭断言：输入一个块内字符，输出要么是映射后的 ASCII，要么为空（删除），且不得等于原字符（除非该原字符本身已是允许 ASCII，全角块里没有这种情况）。
- OpenCC 只在 `convertText` 内部使用，UI 不直接依赖词典对象。
